The actual Investment Banking Level 1 is the gameplay master: 29 authored beats, seven scored decisions, six reputation points per decision, first choice at beat six. See ib-level-1-template.json. This edition supersedes the older ten-decision pilot and interactive supporting-graphic guidance.

UX Designer and Food Scientist are revised QA candidates built on that contract. Supporting work graphics are read-only. Only the established game questions require interaction. Human QA remains pending; source checks cannot certify subject accuracy or drawing quality.

Every recurring person has one canonical face, complexion and iris reference in the v6 cast ledger. Compare every new scene against that reference and repair drift before selection. Lighting can shift local highlights/shadows, not a person's underlying complexion. Exact image reuse preserves pixels; fresh generation cannot promise pixel-identical results.

Selected complete-scene art is distributed separately from the source ZIP to keep individual downloads manageable. Older v4 art and QA records are historical, not the current scene selection. The source package extends the Dreamari engine and is not a standalone executable game.
