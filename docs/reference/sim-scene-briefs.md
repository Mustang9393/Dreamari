## 1. Rules for every scene

### Framing (the dialogue box and HUD sit on top of your painting)

Pixel numbers are for 1672x941.

| Rule | Why | In pixels |
|---|---|---|
| **Faces in the upper 55%** | The dialogue box covers the bottom. | Every face between y 75 and y 518. |
| **Keep the top 8% clear of faces** | The progress bar and score sit there. | No face above y 75. |
| **Main face in the centre 60% across** | A phone shows only about a quarter of the width. We slide that window to the face. A face near the edge gets cut off. | Main face between x 334 and x 1338. |
| **Two people: tight** | The phone window is about 420 px wide (of 1672). Both faces must fit inside it, or the phone loses one. This is the one problem with the IB reception and boardroom two-shots. | Both faces inside one 420 px wide column. Stagger them in depth: one a step behind the other's shoulder, heads at slightly different heights. |
| **Bottom third: nothing important** | The dialogue box covers it. | Below y 627: floor, desk edge, blur, forearms only. |
| **POV "doing the job" shots** | Hands and tools are the point, so lift them out of the dialogue box. | Hands and the object they work on sit between y 330 and y 610. Forearms enter from the bottom corners. |
| **Eye level unless the brief says POV** | It matches the IB set and keeps faces readable. | Camera at standing eye height, about 35 to 50 mm, no tilt, no fisheye. |

### One light, one sun, a real time of day

- **One key light per scene**, named in each brief. Ceiling lights can glow, but they must not throw a second set of shadows. If the sun is in the window, it is the only sun.
- **Time of day follows the story.** Each game has a light plan below. Golden hour shows up only where the brief asks for it.
- **Vary the window view.** Each location below has its own view. The same downtown skyline should not appear in every room.

### Universal AI-tell checklist (check every image against this)

From the first IB batch:

- [ ] **One sun, one light source.** Shadows all fall the same way.
- [ ] **No duplicated logos.** At most one company mark in frame, and only where the brief allows it. No real brands.
- [ ] **No gibberish text.** Screens, signs, charts, whiteboards and papers show simple abstract shapes, coloured bars or blank space. No letters or numbers unless the brief asks for them. (IB `l2-09` reads "COLBALT"; this is the problem.)
- [ ] **No faceless clone extras.** Every background person has a different face, hair, skin tone and build, doing a different thing. Blur them instead of cloning them.
- [ ] **Consistent proportions.** Realistic adult bodies at the same scale. No one bodybuilder-sized (IB Marcus is too broad in `christina-man-boardroom-sunset`).
- [ ] **Professional, school-appropriate dress.** Shirts and blouses buttoned to the collarbone. Scrub V-necks at standard depth. No low necklines (several IB sprites have them: Cobalt HR, Lamisa, Yvonne).
- [ ] **Not golden hour everywhere.** The light matches the time the brief names.
- [ ] **Not the same skyline in every shot.** Use the window view the location sheet gives.
- [ ] Hands: five fingers, no fused or extra fingers, tools held the way a real person holds them.
- [ ] The same character looks the same across scenes: hair, skin tone, height and outfit match the cast sheet.

### House style (already inside every prompt below)

Each prompt ends with the same **style line**, so all three games look like one family:

> Style: polished 2D anime illustration matching the attached Cobalt Capital scenes, clean confident line art, soft cel shading with two-tone shadows, natural saturated colour, a detailed background painted in the same style (not photographic, not 3D). 16:9, 1672x941. Realistic adult proportions. Professional, school-appropriate clothing with collars and necklines closed to the collarbone.
